## 当前实验是什么

- 平面二连杆机械臂，杆长 0.5 m 和 0.4 m，质量 2 kg 和 1.5 kg，均匀杆惯量。
- 末端负载建模为刚性附着点质量，不包含抓取、夹爪、碰撞或滑移。
- 三种控制器：PD 加重力补偿、标称计算力矩控制、饱和函数滑模控制。
- 三种工况：标称、额外 0.5 kg 负载、0.5 kg 负载与三倍关节黏性摩擦及短时关节扰动力矩组合。
- 扰动力矩为 4.0—4.2 s 的 `[3; -1.5]` Nm；这不是通过雅可比映射的笛卡尔外力，两者不得混称。
- 标称模型始终使用零负载和标称摩擦，没有读取真实未知参数。
- 每组 8 s，默认控制周期 2 ms；控制与扰动零阶保持，状态用 RK4 积分。
- 所有工况共用相同控制参数与力矩限制；当前参数是开发初值，不代表调参充分的最终基线。
- 初始位置、速度等于参考初值，当前测试只比较跟踪与抗扰，尚未覆盖初始误差收敛。

这些参数属于简化模型，不是 Panda 参数。本实验没有 VLA、MuJoCo、RBF 或自适应权值更新，不代表最终七自由度机器人实验已完成。

## 模型检查与指标

程序检查多个姿态、负载下的惯性矩阵正定性、`Mdot - 2C` 的反对称性质，以及零速度时重力补偿的平衡残差。

关节 RMSE 定义为 `sqrt(mean(e1^2 + e2^2))`，末端误差使用欧氏距离；力矩 RMS 对两关节合并计算。力矩变化指标为差分导数的 RMS，依赖采样设置，比较时必须固定周期。饱和占比为至少一个关节原始指令超限的采样比例。

减半控制周期会同时改变控制采样和积分步长，可用于数值敏感性检查，但不是纯积分器收敛测试。有限仿真不能代替 Lyapunov 稳定性证明。
