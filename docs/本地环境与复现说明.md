# 本地环境与复现说明

## 环境与来源

- 实测机器：macOS Apple Silicon；MATLAB R2025b。
- Python 3.14 项目虚拟环境：`project/.venv`。完整包版本见 `requirements-local.lock.txt`。
- MuJoCo 3.17.0；无需 CUDA 或云端 GPU，即可执行这里的物理仿真。
- Panda 来自 Google DeepMind MuJoCo Menagerie，提交 `a662de603224c47123b0783821c58ad4402ad3e3`；只检出 `franka_emika_panda`。来源：https://github.com/google-deepmind/mujoco_menagerie 。保留原模型及其 LICENSE。
- Python 官方接口与 macOS 渲染要求：https://mujoco.readthedocs.io/en/stable/python.html 。当前脚本使用离屏渲染，不启动交互窗口。

本地环境不是未来 OFT 的复现环境，不在这个 Python 环境里安装旧版 robosuite 或 VLA 依赖。云端建立单独 Python 3.10 环境。

## 一次运行全部本地实验

在终端进入 project 后运行：

```bash
./run_local_all.sh
```

脚本会更新同名结果。需要保留旧版本时，先复制结果文件夹。MATLAB 需要可用许可证。视频渲染需要当前 macOS 登录会话允许图形访问；严格隔离的沙箱可能出现 `invalid CoreGraphics connection`，本次在普通本机会话执行后已成功。

也可以分开运行：

```bash
matlab -batch "addpath('matlab'); run_local_suite;"
.venv/bin/python python/build_cartesian_reference.py
.venv/bin/python python/run_panda_local.py --video
.venv/bin/python python/run_panda_local.py --cartesian
.venv/bin/python python/verify_local.py
.venv/bin/python python/analyze_local.py
```

后两个脚本依赖前序结果存在；完整分析还需要 `local_suite_dt1ms`，首次推荐使用一键脚本。

## 数据说明

- `results/local_suite/summary.csv`：240 个 MATLAB 回合；每种工况和方法保存首个测试种子的详细 CSV。
- `results/local_suite/experiment.mat`：配置、模型检查、首个测试种子详细轨迹和全部指标。
- `results/local_suite_dt1ms/`：48 个采样周期减半回合。
- `results/panda_local/`：60 个 Panda 关节参考回合，首种子的详细 NPZ、视频、图片和汇总。
- `results/panda_cartesian/`：60 个笛卡尔参考经 IK 转换的 Panda 回合。
- `results/cartesian_reference/`：平滑参考及 IK、导数、关节限位检查。
- `results/local_checks.json`：模型隔离、实际力矩配置、Coriolis 极化等验证。
- `results/fair_tuning_v2/`：修复后 96 开发、126 独立、27 噪声回合，全部零接触。
- `results/fair_tuning_v1_original/`：修复前历史数据，含零力指尖垫初始化接触。
- `results/grasp_transport/`：45 个物理接触抓取回合、视频、接触对比图。
- `results/grasp_transport_ext/`：1× 原始夹爪 6 种子 90 回合。
- `results/grasp_transport_grip15/`：论文正式平台（1.5× 校准夹爪）90 回合、视频、对照图和 `platform.json`。
- `results/grasp_transport_v1_original/`：共享控制器替换前的归档，指标与当前批次一致。
- `docs/夹爪力校准对照报告.md`：1×/1.5× 成功率、连续指标和视频索引。
- `results/gripper_bench/`：独立夹爪上拉容量扫描与图。
- `results/contact_audit/`：异常种子复现和修复后复核。
- `results/grasp_diagnostics/`：接触位置、法向和力日志。
- `results/analysis/`：对比热力图、接触审计图和当前源码/数据版本。
- `docs/本地阶段完成报告.md`：从原始 CSV 自动生成的结果表。

Panda NPZ 中 data 为二维数组，columns 是字段名称，不应通过猜测列位置读取。记录状态、参考、力矩、误差、网络输出、外力和饱和标志。所有测试回合均保留汇总，不按结果好坏删回合。

## 模型改动

原始 XML 文件没有覆盖。加载后只把七个机械臂位置执行器改成单位增益、零偏置的力矩执行器；夹爪继续使用原始执行方式。真实模型手部惯性坐标处增加刚性质量与球形近似惯量；标称模型保持原始参数。该负载不可见，不代表已经仿真抓取物体。

真实组合工况把前七个关节阻尼乘三，并在 3.0—3.2 s 对手部施加世界坐标外力 `[8,-4,0]` N。第一轮 MATLAB 使用的是关节力矩扰动，不能把两者的数值直接比较。

自由跟踪轨迹处于小范围自由空间。旧版负载工况因 `mj_setConst` 重置 `MjData` 而让夹爪从闭合状态起步，产生零力指尖垫接触；修复后 249 个自由运动回合全部零接触。接触抓取任务由 `grasp_transport.py` 单独实现，含桌面、自由关节方块、目标区和物理摩擦，不是自由空间实验。

## 外置磁盘注意事项

当前外置盘会生成 AppleDouble `._` 旁文件，导致 MuJoCo 将 `._libactuator.dylib` 当作插件加载，或 pip/Git 报元数据警告。本次仅清理了新建 `.venv` 和 vendor 目录内的这些旁文件，没有修改课件。以后重新安装或复制环境后若复发，优先将运行环境放到本机原生文件系统；不要清空或删除真实 `.dylib`、模型和包文件。
